```text
I want to deeply understand the following concept:

[INSERT CONCEPT]

Teach it using this framework:

1. BIG PICTURE
- Explain what problem this concept solves.
- Explain why it exists.
- Explain where it fits in the larger system.

2. ANALOGY FIRST
- Give 3 different analogies:
  - A real-world analogy
  - A business/work analogy
  - A daily-life analogy
- For each analogy explain:
  - What maps to what
  - Why the analogy works
  - Where the analogy breaks down

3. FIRST PRINCIPLES
- Break the concept into its most fundamental components.
- Explain each component in simple language.
- Avoid jargon until necessary.

4. VISUAL MENTAL MODEL
- Create an ASCII diagram showing how everything connects.
- Help me visualize the flow or structure.

5. FEYNMAN EXPLANATION
- Explain it as if teaching a smart 12-year-old.
- Use simple words and concrete examples.

6. STEP-BY-STEP WALKTHROUGH
- Show a realistic example from start to finish.
- Walk through what happens internally at every step.

7. COMPARE AND CONTRAST
- Compare this concept against similar concepts.
- Explain when to use each.
- Highlight common misconceptions.

8. ENGINEERING PERSPECTIVE
- Explain why an engineer would care about this.
- Explain tradeoffs, benefits, and limitations.
- Explain real-world use cases.

9. EDGE CASES
- Explain situations where this concept fails.
- Explain common mistakes beginners make.

10. MEMORY AIDS
- Create:
  - A simple mnemonic
  - A memorable story
  - A one-sentence summary
  - A 30-second explanation

11. KNOWLEDGE GRAPH
- Show how this concept connects to related concepts.
- Explain prerequisites and next concepts to learn.

12. ACTIVE RECALL QUESTIONS
- Create 10 questions that test understanding.
- Include increasing difficulty levels.

13. INTERVIEW QUESTIONS
- Create beginner, intermediate, and advanced questions.
- Provide ideal answers.

14. REAL-WORLD APPLICATION
- Show how companies or engineers use this concept in practice.

15. LEARNING CHECK
Ask me:
- What problem does this solve?
- How would I explain it to a child?
- What is the analogy?
- What are the limitations?
- How is it different from similar concepts?

16. 80/20 SUMMARY
- Tell me the 20% of ideas that provide 80% of understanding.

```
